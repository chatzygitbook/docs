### Add-Ons

**Conversational AI Credits**  
- 1 credit = **per 4000 tokens** processed.  
- A message is defined as one complete interaction, i.e., a user query + chatbot response.
- Each such exchange consumes 1 credit, regardless of the length of the response (up to 4000 tokens per credit).

**WhatsApp Credits**  
- Marketing: ₹ 0.88 <br/>  
- Utility: ₹ 0.125 <br/>  
- Authentication: ₹ 0.125​​ <br/>  
- Service: Unlimited Free Service Conversations
