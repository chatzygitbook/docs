### How Credits Work (Important)

At Chatzy AI, every AI interaction starts with a **4,000-token context window**, which equals **1 credit** (for GPT-4o).

Token usage per credit varies across models.


#### Model-Based Multipliers

| **Model** | **Credits per 4000 Tokens** |
|-----------|--------------------------|
| GPT-4o 128K | 1 |
| GPT-4o-Mini 128K | 0.15 |
| Claude Sonnet 4 200K | 1.2 |
| Claude 3.5 Haiku 200K | 0.4 |
| Gemini 2.5 Flash 1M | 0.3 |
| Gemini 2.5 Flash Lite 1M | 0.15 |
| GPT-5 400K | 0.7 |
| GPT-5-Mini 400K | 0.3 |
| O4-Mini 200K | 0.5 |

**If your content exceeds 4,000 tokens, your usage scales proportionally**.  

---

#### Understanding Token Usage
- **1 token ≈ 4 English characters**  
- **4000 tokens ≈ 16,000 characters** (roughly the size of a short blog post)

This 4,000-token space is shared across:

1. Your prompt  
2. Any function/image/video prompts  
3. Your retrieved context (RAG)  
4. Your chat history  
5. The AI’s internal reasoning + final answer
