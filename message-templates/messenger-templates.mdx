The **Messenger Message Templates** section is where you can design and manage rich, structured messages for your Facebook Messenger chatbot.  
Unlike WhatsApp, Messenger offers a wider range of **pre-defined template categories** to choose from.

## Template Categories
<Frame>
  <img src="/message-templates/messenger-templates/msg2.png" alt="Choosing the category of a new Messenger template" className="rounded-lg" />
</Frame>

When creating a new template, you must select a **category**, which determines its content and format:

- **TEXT** → Send simple, plain-text messages to users.  
<Frame>
  <img src="/message-templates/messenger-templates/msg3.png" alt="Creating a Messenger template made of text" className="rounded-lg" />
</Frame>
- **IMAGE**, **VIDEO**, **AUDIO**, **FILE** → Send rich media content. Each template is configured for a specific file type.  
<Frame>
  <img src="/message-templates/messenger-templates/msg4.png" alt="Messenger template built around an image" className="rounded-lg" />
</Frame>
- **BUTTON** → Create a message with a clickable button that directs the user to a website or external link.  
<Frame>
  <img src="/message-templates/messenger-templates/msg5.png" alt="Messenger template with a button that links out" className="rounded-lg" />
</Frame>

- **QUICK_REPLY** → Send a message with a set of predefined quick reply options, helping guide the conversation and capture fast responses.  
<Frame>
  <img src="/message-templates/messenger-templates/msg6.png" alt="Messenger template offering quick replies" className="rounded-lg" />
</Frame>
- **GENERIC** → Build rich, interactive cards with title, subtitle, image, and buttons in a single template. Commonly used for showcasing products, services, or structured listings.  
<Frame>
  <img src="/message-templates/messenger-templates/msg7.png" alt="Messenger template built as a card with buttons" className="rounded-lg" />
</Frame>
---

> 💡 **Tip:** Use **Generic Templates** when you need to display multiple items (like product catalogs or service packages) in a scrollable carousel format.
