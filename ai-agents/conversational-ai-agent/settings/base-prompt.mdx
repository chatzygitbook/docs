# Base Prompt

The **Base Prompt** is where you define how your AI agent should think, behave, and respond. 

Use the Base Prompt editor to:

- Define the agent's purpose and responsibilities
- Set the tone, personality, and communication style
- Create conversation flows and response guidelines
- Add business rules, instructions, and guardrails
- Configure tools, APIs, and WhatsApp interactions directly from the prompt

> **Example:**
>
> `You are Ava, ChatzyAI's customer support assistant. Your goal is to answer customer queries, provide product information, and help users resolve issues.`
>
> `Be friendly, professional, and concise.`
>
> `Always greet the user, understand their requirement, and provide the most relevant solution.`
>
> `If the user requests pricing information, provide available plans and direct them to the sales team when required.`

## Accessing Tools, APIs, and WhatsApp Components

Internal Tools, External APIs, and WhatsApp components are easier to discover and configure directly from the prompt editor.

Simply type `/` anywhere inside the Base Prompt editor to view available options.

Using `/`, you can quickly:

- Add Internal Tools
- Connect External APIs
- Insert WhatsApp Interactive Buttons
- Configure utility actions
- Access supported integrations

> We highly recommend exploring the `/` menu while building prompts, as it significantly speeds up agent configuration.

## Autosave and Version Control

The platform now includes **Autosave** and **Version Control** for:

- Conversational AI Agents
- Flow-Based AI Agents
- Journeys

As you make changes, they are automatically saved to your **Working Draft**.

Once you're satisfied with your updates, you can:

- Save the current state as a version checkpoint
- Create drafts for experimentation
- Review previously saved versions
- Test different versions in the Playground
- Publish the version that best fits your use case

This allows you to safely iterate on prompts and configurations without losing previous work.

> **Tip:** Use version checkpoints before making major prompt changes so you can easily compare results and roll back if needed.
