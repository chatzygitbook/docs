
The **Advanced Settings** tab gives you more control over how your AI agent uses tokens, manages context, and processes knowledge base content.

## Max Tokens

**Max Tokens** defines the maximum number of tokens available to the AI agent while processing and generating a response.

You can increase or decrease the limit using the slider.

A higher token limit gives the agent more room for processing context and generating responses, while a lower limit can help control token usage.

> **Tip:** For most use cases, the default value is a good starting point. Increase it when your agent needs to handle larger amounts of context or generate more detailed responses.

---

## Token Distribution

**Token Distribution** controls how the available context is distributed across different parts of the AI agent's input and output.

The available allocation is divided into:

- **Base Prompt + Function Call + Images and Videos**  
  Space allocated for the agent's instructions, function calls, and media.

- **Context**  
  Space allocated for information retrieved from the agent's knowledge base.

- **Chat History**  
  Space allocated for previous messages in the conversation.

- **Response + Reasoning**  
  Space allocated for generating the response and reasoning.

You can adjust the distribution by moving the handles on the slider.

> **Tip:** The distribution should be adjusted based on your use case. For example, agents that rely heavily on conversation history may benefit from allocating more space to **Chat History**, while knowledge-heavy agents may benefit from more **Context**.

---
## Adjust Chunks

Enable **Adjust Chunks** to manually control how much knowledge base content can be included in the agent's context.

When enabled, you can configure:

- **# Chunk** — The number of chunks retrieved from your knowledge base.
- **Chunk Length** — The size of each chunk in characters.

The **Context** allocation under Token Distribution is automatically calculated using:

```text
Context = # of Chunks × Chunk Length
```

> **Tip:** Increasing the number of chunks can allow the agent to retrieve information from more sections of your knowledge base, while adjusting the chunk size controls how much content is included from each section.
