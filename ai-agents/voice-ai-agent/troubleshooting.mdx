
Most voice problems trace back to one setting. Check the tables below before rewriting your prompt.

## Reading Your Call Logs

Open each call in the [Dashboard](/ai-agents/voice-ai-agent/dashboard) and look for these signals:

| Signal in the logs | Likely cause | What to change |
| --- | --- | --- |
| Many very short calls hung up by the caller | Greeting too long, wrong language, or the caller doesn't know why you're calling | Shorten the greeting; say who you are and why in the first sentence |
| Calls ending exactly at the time limit | No clear ending, or the agent loops | Check **End of Call** is on; add a clear wrap-up rule to the prompt |
| Calls hung up by the agent after silence | Timeout too short for the task | Raise the silence timeout or the check-in delay |
| Wrong or invented answers | Missing or outdated knowledge | Use **Revise Answer** in the call log, add an FAQ, and **Retrain** |
| Caller repeats themselves | Transcriber or language mismatch, noisy line | Try another transcriber or a single-language setting |
| Agent talks over the caller | Endpointing too low | Raise **Endpointing** in the Engine tab |

> 💡 **Tip:** Make one change at a time, **Save version**, and compare the next batch of calls with the last.

## Common Problems

| Problem | Check first | Fix |
| --- | --- | --- |
| Changes don't show on live calls | Is the change only in the **Working draft**? | **Save version**, then **Publish** |
| Agent replies too slowly | Endpointing, Buffer Size, model | Lower Endpointing or Buffer Size a step; try a faster model; consider Speech-to-Speech if you don't need tools |
| Agent cuts callers off | Endpointing, words before interrupting | Raise Endpointing; raise the word count slightly |
| Agent mishears names or numbers | Language and transcriber | Match the language exactly; try another transcriber; ask the caller to repeat, then read it back |
| Wrong gender or language in replies | Prompt and voice | State persona gender and language in the prompt; pick a voice of the same gender |
| Agent can't book or transfer | Mode and tools | Switch to **Standard**; connect Cal.com; turn on **Transfer calls to a human** |
| Booking lands on the wrong day | Utilities | Turn on **Include Date & Time Context** |
| Calls drop after a few seconds of silence | Silence timeout | Raise the timeout, or turn on **User Online Detection** so the agent checks in first |
| Can't place real calls | Channels → Voice | Connect or buy a number and check you have Voice AI minutes left |
