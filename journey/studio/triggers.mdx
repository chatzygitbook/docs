
## Adding a Trigger

The first step in creating a journey is selecting a **trigger**, which is the event that starts the journey.
You can choose from several trigger options depending on your use case.

![triggers-overview](/journey/studio/triggers/triggers.png)

## Trigger Types

### Inbound Webhook

The **Inbound Webhook** trigger allows your journey to start when data is sent from an external system, like CRMs, forms, or from another AI agent within Chatzy AI.

**Setup Steps:**
1. Create a unique webhook URL in the platform.
2. Configure your external app to send a POST request to this URL.
   - Example: Appointment booking details sent to the webhook.
3. Refresh the webhook to view incoming data and map fields (for example, `name`, `phone_number`, `appointment_date`).
4. Select a contact identifier (phone number or Conversation ID).
5. Contact Identifier Value  

   If you select **Phone Number** as the contact identifier, use:  

   ```handlebars
   {{inbound_webhook.inbound_webhook.phone_number}}
   ```

   If you select Conversation ID as the contact identifier, use:
   ``` handlebars
   {{inbound_webhook.inbound_webhook.conversation_id}} 
   ```

 

- Use mapped variables inside the journey with `{{inbound_webhook.variables.       }}`.
   - Example: “Hi `{{{{inbound_webhook.variables.customer_name}}}}`, Your appointment is confirmed for `{{inbound_webhook.variables.appointment_date}}`.”


### Conversation-Based Trigger

This starts a journey when a user initiates a chat on a channel (WhatsApp, Instagram, Messenger, etc.).

</Frame>
</Columns>
**Setup Steps:**
1. Select the channel to monitor.
2. Choose the event type:
   - **Conversation Created** → triggers every time a new conversation starts  
   - **First Conversation Created for Contact** → triggers only the very first time a customer messages you  
   - **Conversation Resumed** → (optional, used when an existing conversation restarts)  

3. (Optional) Add keyword conditions or exclusions.
  Conditions allow fine control over when the journey runs:  

   - **Template Message Condition (WhatsApp only)**  
    Example: Replies to “Day 1” template → Assign AI Agent A  
    Replies to “Day 3” template → Assign AI Agent B  

   - **Keyword Condition**  
    Example: Customer replies with *“Book Appointment”* → Assign Appointment AI Agent  
    Customer replies with *“Tell Me More”* → Assign Product Info AI Agent  

   - **Exclude Keywords**  
    Example: Journey A triggers only for “Pricing”  
    Journey B excludes “Pricing” to handle all other messages  

   If no conditions are set, the journey will run for **all new conversations**.  
   <br/>
   **Example:**
   If a user messages “pricing” on WhatsApp, the chatbot launches the **Pricing Information Journey** immediately.

### Contact Added to List

This trigger starts a journey whenever a new contact is added to a list (such as onboarding or welcome flows).

![list-trigger](/journey/studio/triggers/trigger4.png)

**Setup Steps:**
1. Select the target list (for example, New Leads, Newsletter Subscribers, Trial Users).
2. Define the journey actions, such as sending a welcome message, onboarding flow, or automated follow-up.

**Example:**
When a lead is added to the **New Leads** list, the journey begins with a welcome message and next-step guidance.
