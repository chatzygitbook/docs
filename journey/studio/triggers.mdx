## Visual Journey Builder Studio

Use the **Visual Journey Builder Studio** to design and customize how your journey flows from the initial trigger to various automated actions.

## Adding a Trigger

The first step in creating a journey is selecting a **trigger**, which is the event that starts the journey.
You can choose from several trigger options depending on your use case.

![triggers-overview](/journey/studio/triggers/triggers.png)

## Trigger Types

### Inbound Webhook

The **Inbound Webhook** trigger allows your journey to start when data is sent from an external system, like CRMs, forms, or e-commerce platforms.

![webhook-trigger](/journey/studio/triggers/trigger1.png)

**Setup Steps:**
1. Create a unique webhook URL in the platform.
2. Configure your external app to send a POST request to this URL.
   - Example: A form submission sends details to the webhook.
3. Refresh the webhook to view incoming data and map fields (for example, `name`, `email`, `order_id`).
4. Select a contact identifier (phone number, email, etc.).
5. Use mapped variables inside the journey with `{{variable_name}}`.
   - Example: “Hi `{{name}}`, we received your order `{{order_id}}`.”

### Shopify - Abandoned Checkout

Designed for Shopify stores, this trigger helps recover lost sales by messaging customers who abandoned their carts.

![shopify-trigger](/journey/studio/triggers/trigger2.png)

**Setup Steps:**
1. Connect your Shopify store.
2. Set the wait time before contacting customers.
   - Example: Wait 30 minutes after cart abandonment.
3. Personalize messages using cart details.
   - Example: “Hi `{{name}}`, you left `{{product_name}}` in your cart.”

### Conversation-Based Trigger

This starts a journey when a user initiates a chat on a channel (WhatsApp, Instagram, Messenger, etc.).

![conversation-trigger](/journey/studio/triggers/trigger3.png)

**Setup Steps:**
1. Select the channel to monitor.
2. Choose the event type:
   - Conversation Created
   - First Conversation for Contact
   - Conversation Resumed
3. (Optional) Add keyword conditions or exclusions.
   - Trigger only on template replies.
   - Trigger only if a user does not reply to a template.
   - Include or exclude specific keywords.

**Example:**
If a user messages “pricing” on WhatsApp, the chatbot launches the **Pricing Information Journey** immediately.

### Contact Added to List

This trigger starts a journey whenever a new contact is added to a list (such as onboarding or welcome flows).

![list-trigger](/journey/studio/triggers/trigger4.png)

**Setup Steps:**
1. Select the target list (for example, New Leads, Newsletter Subscribers, Trial Users).
2. Define the journey actions, such as sending a welcome message, onboarding flow, or automated follow-up.

**Example:**
When a lead is added to the **New Leads** list, the journey begins with a welcome message and next-step guidance.
