
The **Update Conversation** action modifies the properties of an ongoing conversation. It is useful for adding context, updating status, or storing notes that can be referenced in reporting or by a human agent.

#### Configuration Fields

- **Conversation ID**  
  The unique identifier for the conversation to be updated. You can use a variable such as `{{conversation_id}}` to automatically apply updates to the current conversation within the journey.

- **Params**  
  Key-value pairs used to update conversation details. For example:  
  - `status: Resolved`  
  - `notes: User requested callback`  
  These updates can add metadata, mark progress, or provide additional context for agents.
