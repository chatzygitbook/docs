
The **Remove from Journey** action stops a flow from continuing in a specific journey. This is a critical tool for managing your conversational flows, especially if a user's behavior or a new condition makes a current journey irrelevant or unwanted.

## Configuration Field

- **Journey**: This dropdown allows you to select the specific journey you want the contact to be removed from. This ensures that the user is only removed from the intended journey, especially if they are part of multiple flows at the same time.
