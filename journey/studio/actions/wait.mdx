

The **Wait** action allows you to pause a journey for a specified amount of time. This is useful for creating delays in conversational flows, enabling follow-up messages, reminders, or drip campaigns.

## Configuration Fields

- **Wait**  
  Defines the duration of the pause. Enter a number and select the unit (minutes, hours, or days).

- **Wait Until Specific Time of Day**  
  Toggle option that allows you to hold the journey until a set time is reached. For example, you can configure the flow to wait until **9:00 AM the next day** before sending a message.
